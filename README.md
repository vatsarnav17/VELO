VELO 💸
A vault-based payments tracker for the UPI era

🚀 Overview
Velo is a frontend-first personal finance tool designed to bring intentionality to everyday spending.

In a world of instant UPI payments, where money flows effortlessly, Velo ensures you always know:
👉 where your money is allocated
👉 how much you can actually spend

💡 Core Concept
Instead of relying on a single bank balance, Velo introduces:
Envelope-based capital allocation (Vault system)
Users divide their total capital into multiple “vaults” (envelopes), each representing a spending category.
All transactions are then executed from a selected vault, ensuring better control and awareness.

✨ Features
  🏦 Vault (Envelope) System
    Create, edit, and delete allocation units
    Assign limits and track real-time balances
    Color + icon-based categorization
  💳 Payment Flow
    Initiate payments from a selected vault
    UPI intent integration for real-world transactions
    Automatic deduction from both:
    Vault balance
    Total capital
  🔁 Internal Transfers
    Move funds between vaults
    Maintain allocation flexibility without breaking structure
  📊 Transaction Engine
    Full transaction history (credit, debit, transfer)
    Search + filter by vault and amount
    Undo transactions with state reversal
  💰 Capital Management
    Track total capital vs allocated vs unallocated funds
    Add income entries with source + notes
  🗂️ Monthly Archives
    Save snapshots of your financial state
    Reload previous states anytime
  🧠 Smart Controls
    Validation on allocations (no over-allocation)
    Real-time percentage usage indicators
    Visual warnings for low balances

🛠️ Tech Stack
  Frontend: React.js + TypeScript
  State Management: React Hooks
  Styling: Tailwind CSS
  Icons: Lucide React
  Persistence: LocalStorage (no backend yet)

🔐 Data & Privacy
  All user data is stored locally in the browser
  No external database or API involved (yet)
  Fully offline-capable architecture
